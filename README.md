## 🌐 About The Project

**Siddhi Constructions** is a modern construction company website designed to showcase construction projects, services, company achievements, leadership, awards and client relationships.

The website focuses on a premium visual experience with elegant layouts, smooth animations, responsive sections and professional typography.

## ✨ Features

- 🏢 Professional construction company homepage
- 🎨 Modern UI with premium gradients and styling
- 📱 Responsive desktop, tablet and mobile layouts
- 🏗️ Project and portfolio showcase
- 👷 Leadership and team section
- 🏆 Awards and achievements section
- 🤝 Clients and testimonials
- ⚡ Smooth animations and transitions
- 🧩 Reusable React components
- 🚀 Fast development using Vite

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to Project Folder

```bash
cd Siddhi-Constructions
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

### 5. Open in Browser

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

## 📦 Available Scripts
